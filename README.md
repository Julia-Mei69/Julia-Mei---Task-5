
# Task 5: Exploratory Data Analysis (EDA)

## Project Overview
This repository contains my submission for Task 5. The objective of this project was to conduct an Exploratory Data Analysis (EDA) using Python to understand structural trends, data distributions, and correlations within a dataset. 

## Tools Used
* **Development Environment:** Google Colab (Jupyter Notebooks)
* **Data Manipulation:** Pandas
* **Data Visualization:** Seaborn & Matplotlib

## Key Insights
* **Data Distribution:** Evaluated single-variable attributes and identified a right-skewed distribution in spending behavior.
* **Bivariate & Multivariate Patterns:** Mapped variations across categorical groups using boxplots and isolated distinct weekend spending spikes using a correlation matrix heatmap.
* **Feature Relationships:** Utilized pairplots to visually verify positive linear trends across core numerical features.

## Files in Repository
* `*.ipynb`: The complete executable Python notebook containing data source structures and visualization code scripts.
* `*.pdf`: The final compiled presentation report featuring the written summary analysis alongside the exported visualizations.
